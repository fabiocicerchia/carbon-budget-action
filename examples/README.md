# Examples

Runnable, self-contained examples. Each subfolder shows one clear use case.

- `basic/` — minimal end-to-end workflow using the action.
- `error-budget/` — gate a deploy step on a running carbon total for a
  window (`track-budget`), SRE-error-budget style.
- `ci-platforms/` — the same gate on sixteen non-GitHub CI systems: GitLab CI,
  CircleCI, Travis, Azure DevOps, AWS CodePipeline, Devtron, Northflank,
  Spacelift, Jenkins, Bitbucket Pipelines, Google Cloud Build, Tekton, Argo
  Workflows, Harness, Buildkite, Drone/Woodpecker.
